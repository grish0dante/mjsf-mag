# Лабораторна робота № 4. Створення вкладок із використанням Slots, Provide/Inject, Dynamic Components і KeepAlive

## Мета роботи

Навчитися створювати у Vue 3 складений компонент вкладок (compound component), частини якого обмінюються локальним контекстом через `provide/inject`, відображають панелі за допомогою слотів і динамічних компонентів та зберігають їхній локальний стан за допомогою `KeepAlive`.

## Використані технології

- Vue 3 — створення компонентів інтерфейсу.
- JavaScript — реалізація логіки вкладок.
- Composition API та `<script setup>` — керування реактивним станом.
- Vite — запуск і збірка проєкту.
- Tailwind CSS 3.4.17 — стилізація компонентів.
- SCSS — організація стилів.
- PostCSS та Autoprefixer — обробка CSS.

## Реалізація компонентів

### Tabs.vue

Головний компонент, який відповідає за керування вкладками.

Реалізовано:

- підтримку `v-model` через `modelValue` та `update:modelValue`;
- реєстрацію та видалення вкладок;
- реактивний стан активної вкладки;
- передавання контексту через `provide`;
- три варіанти оформлення: `underline`, `pills`, `boxed`;
- автоматичну активацію вкладок;
- клавіатурну навігацію.

### Tab.vue

Дочірній компонент, який відповідає за відображення окремої панелі.

Реалізовано:

- отримання контексту через `inject`;
- реєстрацію вкладки під час монтування;
- видалення реєстрації перед демонтажем;
- передавання вмісту через слот;
- підтримку динамічних компонентів;
- кешування локального стану через `KeepAlive`;
- підтримку атрибутів доступності WAI-ARIA.

### tabsKey.js

Містить спільний ключ контексту:

```javascript
export const tabsKey = Symbol('tabs')
```

Використання `Symbol` дозволяє уникнути конфліктів ключів ін'єкції.

## Варіанти оформлення вкладок

У застосунку реалізовано три незалежні набори вкладок.

### Underline

Активна вкладка позначається нижньою бірюзовою лінією.

Панелі передаються через слоти компонентів `Tab`.

### Pills

Вкладки мають вигляд заокруглених кнопок.

Панелі створюються динамічно з масиву об'єктів за допомогою `<component :is>`.

### Boxed

Вкладки оформлені як кнопки всередині окремого контейнера.

Демонструється робота з недоступними вкладками та модальним вікном.

Кожен набір має власний активний стан і працює незалежно від інших.

## Slots та динамічні компоненти

У роботі реалізовано два способи передавання вмісту панелей.

**Перший спосіб — Slots.**

```vue
<Tabs v-model="activeTab" variant="underline">
  <Tab slug="overview" title="Огляд">
    <OverviewPanel />
  </Tab>
</Tabs>
```

**Другий спосіб — динамічні компоненти.**

```vue
<Tab
  v-for="item in dynamicTabs"
  :key="item.slug"
  :slug="item.slug"
  :title="item.title"
  :panel="item.panel"
  :panel-props="item.panelProps"
/>
```

Слоти використовуються для статично визначеного вмісту, а динамічні компоненти — для вкладок, сформованих на основі даних.

## Provide / Inject

Для передавання спільного стану використано механізм `provide/inject`.

Компонент `Tabs` надає контекст, який містить:

- `activeSlug` — поточну активну вкладку;
- `idPrefix` — унікальний префікс ідентифікаторів;
- `setActiveTab` — метод перемикання вкладок;
- `registerTab` — метод реєстрації вкладки;
- `unregisterTab` — метод видалення вкладки.

Компонент `Tab` отримує цей контекст без передавання додаткових пропсів через проміжні компоненти.

## KeepAlive

Для збереження локального стану панелей використано вбудований компонент Vue `KeepAlive`.

Після переходу на іншу вкладку локальні дані компонента не втрачаються.

Це продемонстровано на прикладі:

- текстового поля;
- прапорців;
- лічильника;
- коментаря користувача.

Після повернення до вкладки раніше введені значення зберігаються.

## ModalDialog

У панелі одного з наборів вкладок використано компонент `ModalDialog`.

Модальне вікно реалізовано з використанням `Teleport`, що дозволяє відображати його поза основною DOM-ієрархією компонента.

Діалог відкривається та закривається без скидання локального стану панелі.

## Доступність WAI-ARIA

Для забезпечення доступності використано атрибути:

- `role="tablist"` — контейнер вкладок;
- `role="tab"` — кнопка вкладки;
- `role="tabpanel"` — панель вкладки;
- `aria-selected` — стан вибору;
- `aria-controls` — зв'язок кнопки з панеллю;
- `aria-labelledby` — зв'язок панелі з кнопкою;
- `tabindex` — керування клавіатурним фокусом.

Реалізовано автоматичну активацію та навігацію за допомогою клавіш `ArrowLeft`, `ArrowRight`, `Home`, `End` і `Tab`.

Недоступні вкладки пропускаються під час клавіатурної навігації.

## BEM і SCSS

Для найменування CSS-класів використано методологію BEM.

Основний блок — `tabs`.

Елементи:

- `tabs__list`;
- `tabs__tab`;
- `tabs__content`;
- `tabs__panel`.

Модифікатори:

- `tabs--underline`;
- `tabs--pills`;
- `tabs--boxed`;
- `tabs__tab--active`.

Стилі компонентів розміщено у `<style scoped lang="scss">`.

Для оформлення використано директиву Tailwind CSS `@apply`.

Кольори та шрифти централізовано визначено у файлі `tailwind.config.js`.

## Функційна модель IDEF0

**A1 — Керувати вкладками (Tabs)**

- Input: `modelValue`, декларації `Tab`, команди користувача.
- Control: контракт `v-model`, `variant`, правила WAI-ARIA.
- Output: `update:modelValue`, список вкладок, контекст `tabsKey`.
- Mechanism: Vue 3, Composition API, `provide/inject`, реактивний реєстр.

**A2 — Показати панель (Tab)**

- Input: `slug`, `title`, `disabled`, слот або `panel` і `panelProps`.
- Control: контекст `tabsKey`, правила WAI-ARIA.
- Output: відображена активна панель, стан `isActive`.
- Mechanism: lifecycle hooks, `inject`, динамічні компоненти, `KeepAlive`.

## Висновок

У ході лабораторної роботи розроблено систему вкладок на основі Vue 3 із використанням підходу compound components.

Реалізовано взаємодію компонентів через `provide/inject`, передавання вмісту через Slots, створення динамічних компонентів та збереження їхнього локального стану за допомогою `KeepAlive`.

Створено три варіанти оформлення вкладок, реалізовано клавіатурну навігацію відповідно до WAI-ARIA та інтегровано модальне вікно.

Отримано практичні навички побудови повторно використовуваних компонентів Vue, організації локального стану й розробки доступних інтерфейсів.
