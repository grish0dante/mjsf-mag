## Мета роботи

Навчитися створювати компоненти у Vue 3, передавати дані через пропси, обробляти події компонентів і керувати реактивним станом. Реалізувати каталог навчальних матеріалів із фільтрацією, вибором матеріалу та обчисленням підсумкових показників.

## Функціональність

- Відображення карток навчальних матеріалів із назвою, темою, описом і тривалістю.
- Вибір матеріалу та візуальне позначення вибраної картки.
- Фільтрація матеріалів за текстом назви та темою.
- Скидання фільтрів.
- Автоматичне обчислення кількості знайдених матеріалів і сумарної тривалості.
- Повідомлення, якщо за фільтрами нічого не знайдено.

## Використані технології

- Vue 3 — компоненти Single File Components (`.vue`).
- JavaScript — логіка застосунку.
- Composition API та `<script setup>` — стан і обчислення.
- Vite — локальний сервер розробки та збірка.
- CSS — оформлення каталогу.
- Node.js та npm — середовище виконання й керування залежностями.

Точні встановлені версії вказані у `package.json` та `package-lock.json`. Їх можна перевірити командою `npm list vue vite`.

## Опис компонентів

| Компонент | Призначення |
|---|---|
| `App.vue` | Кореневий компонент сторінки, інформація про студента та розміщення каталогу. |
| `MaterialCatalog.vue` | Зберігає вибір і активні фільтри, обчислює відфільтрований список та сумарну тривалість. |
| `MaterialFilterForm.vue` | Форма пошуку й вибору теми; надсилає події `apply` і `clear`. |
| `MaterialCard.vue` | Показує один матеріал, отримує дані через пропси та повідомляє про вибір подією `select`. |
| `data/materials.js` | Початковий масив навчальних матеріалів. |

## Реактивність

- `ref()` — зберігання вибраного матеріалу.
- `reactive()` — стан фільтрів і полів форми.
- `computed()` — фільтрація, кількість результатів і сума хвилин.
- `v-model` — двостороннє зв'язування полів форми.
- `props` і `emit` — обмін даними та подіями між компонентами.

## Встановлення та запуск

Передумови: встановлені Node.js і npm.

Перейдіть у папку лабораторної:

```bash
cd lab2
```

Встановіть залежності відповідно до lock-файлу:

```bash
npm ci
```

Запустіть сервер розробки:

```bash
npm run dev
```

Відкрийте адресу, виведену Vite в терміналі (зазвичай `http://localhost:5173`).

## Збірка та перевірка

Створити production-збірку:

```bash
npm run build
```

Переглянути зібрану версію:

```bash
npm run preview
```

Зупинити сервер: `Ctrl + C`.

| Обрати іншу картку | Змінюється позначення та назва вибраного матеріалу. |
